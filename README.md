# コハクと家計簿 🌿

スマホで支出をさっと記録し、月ごとの円グラフと分類別の金額で振り返る家計簿。

- 金額・日付・分類・メモの登録、編集、削除、連続入力
- 食費 / 光熱費 / 定期購入品 / QOL / 物品 / その他。外食は QOL の内訳
- 日付別一覧、月の合計、カテゴリ別円グラフと内訳
- ブラウザ保存、JSONバックアップの書き出しと復元
- ホーム画面用アイコンとWeb App Manifest。オフライン起動は未対応

## GitHub Pages

リポジトリの Settings → Pages → Deploy from a branch → main / (root) → Save。
この構成はビルド不要で、アプリのファイルを直接配信します。

## 保存と移行

記録はこのブラウザの localStorage に保存します。自動同期やサーバーへの記録送信はありません。
コードの公開と家計簿の記録は別です。バックアップ・実データ・認証情報をGitHubに追加しないでください。
ブラウザのデータを消す前や機種変更前には、バックアップを書き出してください。
Sites版から移る場合は、元のURLで書き出し、新しいURLの「バックアップを読み込む」で復元してください。

## ホーム画面

Chromeで家計簿を開き、メニューのホーム画面への追加を選択します。
対応状況によってインストールまたはショートカット追加として表示されます。
ホーム画面からの起動は設定済みですが、実機での表示は確認してください。

## 開発

## Ver.0.2.0

- 入力画面の分類を押すと、左に大分類・右に小分類が出るボトムシートが開きます。小分類のない項目は1タップで確定。途中で閉じると変更は確定されません。
- 設定の「更新を確認」から `update.html` を開けます。変更内容とバージョンを表示し、通信・ファイル内容の確認後に家計簿へ戻れます。
- 保存キー `kohaku-ledger-v1` とバックアップ形式は変更しません。更新ページはlocalStorageを読み書きしません。
- 配信ファイルは `releases/<version>/` に固定します。今後の変更では `package.json` のバージョン、HTMLの参照先・表示バージョン、リリースノートを更新し、`node scripts/build-release.cjs` を実行してください。公開済みのリリースフォルダは上書きせず残します。
- 更新ファイルはSHA-256で確認します。オフライン起動は引き続き未対応です。

依存パッケージ不要。`python -m http.server 8765 --bind 127.0.0.1` で起動し、`http://127.0.0.1:8765/` を開きます。
検証は `npm test`。PNGアイコンの再生成はWindowsで `pwsh -File scripts/generate-icons.ps1`。
